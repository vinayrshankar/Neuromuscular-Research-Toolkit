# Support

## Before asking for help

1. Check the [documentation index](docs/README.md).
2. Search existing GitHub issues.
3. Confirm the NMRT version, Python version, operating system, sample rate, signal units, and relevant recipe/settings.
4. Reproduce the problem with synthetic or deidentified data whenever possible.

## Bug reports

Use the GitHub bug-report template for crashes, unexpected behavior, data-integrity concerns, or numerical results that appear incorrect.

## Feature requests

Use the feature-request template for new importers, hardware adapters, signal metrics, task workflows, reports, or GUI features. Scientific algorithms should include a validation strategy or reference where possible.

## Sensitive material

Never attach participant identifiers, PHI, credentials, private datasets, licensed vendor binaries, or other material you do not have permission to distribute.
