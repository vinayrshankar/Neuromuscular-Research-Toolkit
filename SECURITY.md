# Security Policy

NMRT processes research data and may eventually interface with laboratory hardware. Security and data integrity issues should therefore be treated seriously.

## Supported versions

During the pre-1.0 development period, security and data-integrity fixes are applied to the current `main` branch and the most recent tagged release.

## Reporting a vulnerability

Please do **not** post credentials, protected health information, identifiable participant data, private datasets, or proprietary vendor files in a public issue.

For a security-sensitive report, contact:

**Vinay Shankar**  
vinay@tfaworld.org

Include the NMRT version, operating system, affected component, impact, and a minimal reproduction that does not contain sensitive research data.

## Research-data safety

NMRT is designed so raw imported data are not silently overwritten. Users remain responsible for their institution's requirements for access control, encryption, retention, backups, deidentification, and IRB/ethics compliance.

NMRT is research software and is not a medical device or clinical decision-support system.
